耳机数据看板 - 用户使用说明

一、Windows 用户如何打开

1. 解压 earphone-dashboard.zip。
2. 进入 EarphoneDashboard 文件夹。
3. 双击“打开耳机数据看板.bat”。
4. 等浏览器自动打开看板。
5. 使用期间不要关闭弹出的命令行窗口；关闭窗口会停止本地服务。

如果 Windows 提示 Python 不存在，请先安装 Python 3，然后再次双击启动文件。


二、项目文件保存在哪里

看板默认把项目文件保存到：

projects/我的耳机项目.json

你可以在页面顶部“项目 JSON 路径”中修改这个路径。建议每个研究项目使用一个独立的 JSON 文件。


三、照片目录如何组织

看板支持两种照片匹配方式。

方式一：照片顺序逻辑

照片根目录下一级文件夹是用户，例如：

photos/
  U001/
    IMG_0001.jpg
    IMG_0002.jpg
  U002/
    IMG_0001.jpg

方式二：子文件夹逻辑

照片路径中需要包含姓名/用户、左右耳、样机/设备、方向/视角这几类文件夹，但层级顺序不限，例如：

photos/张三/左耳/样机A/正面/IMG_0001.jpg
photos/左耳/正面/张三/样机A/IMG_0002.jpg

文件夹名可以带前后缀，例如“姓名-张三”“L-左耳”“样机A_试产”“view_正面”。


四、保存按钮的区别

保存当前配置：
只保存布局、字段角色、透视设置、图表设置、照片匹配方式和视角等配置。

保存完整项目：
保存当前数据、照片映射结果和全部配置。


五、注意事项

1. 不要直接双击 app/index.html 使用完整功能；项目保存、照片扫描需要本地服务。
2. 如果双击启动后端口被占用，启动器会自动尝试 8000-8099 之间的可用端口。
3. 如果仍无法启动，可能是安全软件或单位电脑策略禁止 Python 监听本地端口，需要联系 IT 放行 Python 的 localhost 访问权限。
